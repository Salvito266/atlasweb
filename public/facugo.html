Preguntas Frecuentes

Todo lo que necesitas saber

¿Funciona con mi sistema de agenda actual? +
Sí. FacuGo se integra con Medilink, AgendaPro, Bookify, Encuadro y Google Calendar de forma nativa.
¿Cuánto tiempo toma la implementación? +
El proceso de onboarding toma aproximadamente 5 horas de trabajo conjunto para configurar respuestas y calendario.
¿Qué pasa si quiero cancelar? +
Todos nuestros planes tienen permanencia mínima de 6 meses para amortizar el setup inicial.
¿El precio sube con el tiempo? +
El precio se reajusta anualmente según el IPC acumulado del año anterior.
¿Necesito tener landing page o sitio web? +
No necesariamente. El agente puede funcionar solo desde WhatsApp.
¿Qué pasa si un paciente hace una pregunta muy específica? +
FacuGo está configurado para derivar al equipo humano cuando la consulta requiere criterio clínico o un caso complejo.
